# Рулетка исторических тем

510 тем для разговорного багажа: странные убийства, безумные правители, шпионы,
мистификации, войны по нелепым поводам. Свайп по экрану крутит барабан,
выпавшая тема больше не повторяется.

```bash
npm install
npm run dev
```

`npm run build` — сборка, `npm run lint` — проверка кода.

## Как устроено

**Свайп** (`src/lib/useSwipe.ts`) слушает pointer-события на всём окне, поэтому
одинаково работает пальцем и мышью. Порог — 55 px в любую сторону.

Ограничения по длительности жеста намеренно нет: на главном экране ничего не
прокручивается, конкурирующих жестов не существует, а неспешный свайп — такой
же свайп. Лимит только порождал бы «провёл пальцем, но ничего не вышло».

Кнопки экрана жест не гасят: короткий тап не дотягивает до порога, а при
протяжке с кнопки браузер не отправляет `click`, потому что палец отрывается уже
вне её. `data-no-swipe` остался только на всплывающих панелях с прокруткой.

**Барабан** (`src/components/Reel.tsx`) — настоящая вертикальная лента из 38
строк, которая едет через окно высотой в 5 строк. Торможение задано кривой
`cubic-bezier(0.16, 0.84, 0.28, 1.06)`: последнее значение больше единицы, то
есть лента проскакивает нужную строку примерно на 20 px и откатывается назад,
как механизм с инерцией. Ради этого отката под выигрышной строкой лежит запас
в три строки. Края гасятся `mask-image`, на разгоне добавлен лёгкий смаз,
который снимается за 1,4 с до остановки — чтобы последние строки уже читались.

Завершение — по таймеру, а не по `transitionend`: это событие теряется, если
вкладку свернули во время прокрутки.

**Неповторяемость.** Выпавшие номера лежат в `localStorage`
(`src/lib/storage.ts`), выбор идёт только из оставшихся. Тема засчитывается в
момент остановки барабана, не раньше, — иначе прерванный спин съедал бы тему.

## Экраны и возможности

- Счётчик «осталось / выпало» и полоса прогресса.
- **Разделы** — фильтр по 24 рубрикам с остатком в каждой; пусто = все.
- **Выпало** — история, свежие сверху, любую тему можно вернуть в барабан.
- Копирование темы в буфер; если буфер недоступен, кнопка честно об этом пишет.
- Сброс истории в два нажатия.
- Клавиатура: пробел или Enter тоже крутят.

## Данные

`src/data/topics.json` — 510 тем, разобранных из исходного markdown:

```jsonc
{ "n": 1, "title": "Убийство Джека-потрошителя — кто он был на самом деле?",
  "category": "Странные и нераскрытые убийства", "categoryIndex": 0 }
```

`n` — номер из исходного списка, он же стабильный id: история переживает
изменения текста, но не перенумерацию.

это содержимое исходного файла.
